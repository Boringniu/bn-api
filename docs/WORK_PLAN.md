## 最终产品边界

### 私聊 Bot

- 支持编号、编号前缀、演员/别名、标准标签与 `#原始话题` 的目录查询。
- 返回文字编目结果并支持回调翻页，不发送媒体文件；未识别或未收录时会给出可执行的查询示例。
- `/stats` 显示已审核媒体、编号、文件和最近更新时间；管理员额外看到待审核与重复候选汇总。
- `/duplicates` 仅管理员可用，按相同 Telegram 文件列出待核对候选；该命令不会自动合并或删除记录。
- `/index` 用于跳转频道索引；`/refresh` 仅管理员可用，用于刷新置顶索引。

### Telegram 频道

- 频道内容保留原始媒体和 Bot 维护的置顶索引消息。
- 新媒体会登记标题、编号、演员、话题、Telegram 文件标识和消息映射。
- 未知或歧义标签保留为自由话题；未知演员和歧义演员别名进入审核队列。
- 原视频不做字幕修改、复制替换、删除或重发。
- 审核通过的入库记录可触发置顶索引刷新；索引过长时自动分页。

## 当前可维护项

- 审核结果保存在 D1 的 `review_items` 中；审核接口只保存处理记录与 `config_proposal`。
- 规则修改在 Git 分支中完成，不使用 `review-decisions.json` 或自动生成配置文件。
- 任何 `config/` 变化都必须提升 `config/version.json` 的发布版本。
- 本地与 CI 共用 `npm run check`：配置校验、别名检查、版本单调性、测试、manifest 构建和 Worker 干运行都由该命令覆盖。

## 已知限制

- 公开 HTTP 搜索仅返回 `approved` 内容；待审核项需通过受保护的审核接口读取和处理。
- 标签分类字段仅为兼容保留；当前运行时不自动选定一级分类。
- Telegram 原生 hashtag 只能检索消息本身已有的标签。由于原视频不做修改，置顶索引中的标签不保证能直接定位到旧转发视频。
