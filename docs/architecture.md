# Boringniu 影视库 GitHub 配置标准 v1.0

## 定位

GitHub 是影视库的唯一规则中心。

D1 保存内容事实、配置处理结果和审核记录。Worker、Bot 和管理端只读取已通过校验的配置并执行。AI 只能提出待审核建议，不能直接创建、批准或修改规则。

## 适用范围

- 分类
- 标签
- 演员
- 别名
- 忽略规则
- 频道展示规则
- 搜索规则
- 审核策略
- 配置版本

## 数据所有权

### GitHub

GitHub 配置拥有所有规则定义及其生命周期状态。规则变更必须修改 `config/` 和对应 `schema/`，更新配置版本，并通过 CI 校验与人工审核。

### D1

D1 只保存：

- 来源平台、来源 ID、标题、番号、日期、链接等内容事实。
- 分类、标签、演员的规则 ID 和入库时展示快照。
- 原始输入、归一化结果、规则版本和入库审计事件。
- 未知值、歧义值、异常番号和规则上限违规形成的审核记录。

D1 不保存可独立生效的分类、标签、演员或别名规则，不得作为规则回退源。

### Worker 与 Bot

Worker 与 Bot：

- 只执行仓库中已批准的规则。
- 不自动创建字典项或规则。
- 不自动批准 AI 建议。
- 不直接修改 `config/`。
- 必须记录执行时使用的 `ruleset_version`。

### AI

AI 输出只能作为 `review_items` 中的建议数据。建议必须由具备相应角色的管理员审核，规则变更仍通过 GitHub Pull Request、CI 和合并流程完成。

## 一致性要求

1. D1 关系表保存配置实体 ID，不复制规则判定逻辑。
2. 展示名称允许保存入库快照，但最终规则解释以对应 GitHub 配置版本为准。
3. 未知或歧义标签保留为自由话题，不写入规则词典；未知演员和歧义演员别名进入审核队列，不得静默创建演员或别名规则。当前运行时不自动选定一级分类。
4. 重新入库可以刷新未处理的审核项，不覆盖已完成的人工审核记录。
5. 公共搜索只返回 `approved` 内容；待审核项通过受保护的审核接口读取和处理，不属于公开搜索范围。
