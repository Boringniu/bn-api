# 变更日志（CHANGELOG）

所有配置版本变更按时间倒序记录。格式：版本号、日期、变更内容、涉及文件。

## [1.3.3] - 2026-08-23

- 明确未知或歧义标签保留为自由话题，不再因标签未知创建审核项；未知演员和歧义演员别名仍进入审核队列。
- 删除尚未实现的管理员待审搜索与原始元数据访问配置声明；公开搜索继续只返回 `approved` 内容。
- 新增配置版本单调性检查，并将本地与 CI 统一到 `npm run check`。
- 涉及文件：`search.json`、`version.json`、`search.schema.json`、校验脚本、测试、文档与 CI 工作流。

## [1.3.2] - 2026-07-21

- 自动剥离 `#话题` 末尾的中英文标点。
- 已知演员以 `#话题` 出现时自动归入演员位，不再产生题材审核项。
- `分鍾` 的忽略范围扩展到演员位，避免标题分词误判。
- 涉及文件：`ignored.json`、`version.json` 及 Telegram 编目流程。

## [1.3.1] - 2026-07-21

- 修复 `中出`、`乳交` 使用 Schema 未定义标签类别的问题。
- 移除 `OL` 的多目标别名冲突及两个演员的重复同值别名。
- 修复标签作用域忽略词覆盖合法演员别名的问题。
- 将 1.3.0 新增配置统一为标准 JSON 格式。
- 涉及文件：`actor_dictionary.json`、`tag_dictionary.json`、`ignored.json`、`version.json`。

## [1.3.0] - 2026-07-21

- 新增 8 个演员词条并补充波多野结衣、森泽佳奈别名。
- 新增中出、乳交、强奸、勒索、嫂子诱惑、黑丝OL、乱伦、姐姐、体检等标准标签。
- `无码中字` 归一到中文字幕；演员误标签和噪声词按作用域加入忽略配置。
- 阶段四收口：私聊 Bot 仅查番号；频道只编目和维护置顶索引，原视频不修改、不复制、不重发。
- 涉及文件：`actor_dictionary.json`、`tag_dictionary.json`、`ignored.json`、`version.json` 及 Telegram Worker。

## [1.2.0] - 2026-07-19

- 按配置标准 §五，`无码`、`有码` 属于元数据信息，不得作为标准标签：
  - `tag_uncensored`、`tag_censored` 降级为 `deprecated`，关闭展示与搜索；ID 保留，不得复用，历史关联兼容。
  - `无码`、`無碼`、`无修正`、`uncensored`、`有码`、`有碼`、`censored` 进入忽略词（`ignore_000010`–`ignore_000016`），作用域 `tag` 与 `title_token`。
  - 审查状态应保存至 D1 `media.metadata_json`，不进入频道展示与公开搜索。
- 涉及文件：`tag_dictionary.json`（1.2.0）、`ignored.json`（1.1.0）、`version.json`（1.2.0）。

## [1.1.0] - 2026-07-18

- 扩充演员字典至 27 人（波多野结衣、三上悠亚、河北彩花等）。
- 扩充分类别名。
- 标签字典新增：无码、有码、巨乳。
- 涉及文件：`category.json`（1.1.0）、`tag_dictionary.json`（1.1.0）、`actor_dictionary.json`（1.1.0）、`version.json`（1.1.0）。

## [1.0.0] - 2026-07-18

- 初始规则配置版本。
- 固定五个一级分类：日本、欧美、国产、自拍、AI短剧。
- 首批标准标签、演员、全局别名、忽略词。
- 频道展示、搜索与审核规则基线。
- 全部 9 个配置文件与对应 JSON Schema。
