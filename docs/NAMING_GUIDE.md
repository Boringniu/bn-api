# 命名指南（NAMING_GUIDE）

本文档定义所有标准对象 ID 与名称字段的命名规则。

## ID 命名

| 对象 | 格式 | 示例 |
| --- | --- | --- |
| 分类 | `cat_<slug>` | `cat_japan` |
| 标签 | `tag_<slug>` | `tag_wife` |
| 演员 | `actor_<6 位以上顺序号>` | `actor_000001` |
| 全局别名 | `alias_<6 位以上顺序号>` | `alias_000001` |
| 忽略词 | `ignore_<6 位以上顺序号>` | `ignore_000001` |

硬性规则：

1. ID 一经创建，禁止修改；
2. ID 被废弃后不得分配给新对象；
3. 显示名称可以修改，ID 保持不变；
4. 关系表、D1、Worker 内部一律使用 ID 关联，不使用名称；
5. ID 仅允许小写字母、数字、下划线；
6. 演员 ID 不得根据名称生成，必须使用顺序号（新增时取当前最大号 +1）。

## 名称字段

| 字段 | 规则 |
| --- | --- |
| `display_name`（分类/标签） | 频道与 Bot 展示名，中文优先，最长 30 字符（标签） |
| `display_name_zh_cn`（演员） | 中文简体标准名，频道唯一展示字段，禁止重复 |
| `name_ja` / `name_en` / `romanized_name` | 保留原始字符，不做转写替换，可为 `null` |
| `slug` | 小写字母、数字、连字符，程序内部标识 |

## 别名与标准化值

- `aliases` 保存人工可读原文；`normalized_aliases` / `normalized_value` 保存标准化结果，两者一一对应。
- 标准化规则由 `src/value-normalizer.mjs` 唯一定义：NFKC → 分隔符统一为空格 → 去首尾空格 → 压缩连续空格 → 英文转小写。
- 中文简繁转换仅用于匹配辅助，不得修改标准展示名称。
- 一个标准化别名只能指向一个标准对象。

## 状态值

所有可审核对象使用统一状态集：

```text
approved    已审核，可正式使用
pending     待审核，仅后台可见
ignored     无价值信息，不展示、不搜索
deprecated  已废弃，保留历史兼容
disabled    临时停用，保留记录
```
