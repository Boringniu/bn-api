## Resume procedure (superseded)

The steps below were the original recovery plan; they have all been
executed successfully and are kept only for reference.

1. Verify or renew Wrangler authentication:

   ```bash
   XDG_CONFIG_HOME=/tmp/boringniu-wrangler npx wrangler whoami
   ```

2. Decide whether to create the intended `bn-media` database or deliberately
   reuse one of the existing empty databases. Creating `bn-media` matches the
   repository configuration and README.

3. If creating it, run:

   ```bash
   XDG_CONFIG_HOME=/tmp/boringniu-wrangler npm run db:create
   ```

4. Write the returned database UUID into `wrangler.jsonc`.

5. Apply the migrations:

   ```bash
   XDG_CONFIG_HOME=/tmp/boringniu-wrangler npm run db:migrate:remote
   ```

6. Set the Worker secret without printing its value:

   ```bash
   XDG_CONFIG_HOME=/tmp/boringniu-wrangler npx wrangler secret put INGEST_TOKEN
   ```

7. Deploy and verify:

   ```bash
   XDG_CONFIG_HOME=/tmp/boringniu-wrangler npm run deploy
   ```

   Then request `GET /health` from the deployed Worker URL.
