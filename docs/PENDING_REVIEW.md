# 待审核项与处理说明

本文件用于记录人工维护时的待办和历史决定，不是 Worker 的可执行输入。当前仓库不存在 `review-decisions.json`，也没有由 GitHub Actions 自动修改词典、自动升版本或自动部署的审核决策流程。

## 当前处理方式

1. 通过受保护的审核接口查看 D1 中的 `review_items`，或从实际入库记录中确认需要维护的演员、别名或编号问题。
2. 审核接口可以保存处理结果和 `config_proposal`，但不会直接修改 Git 配置。
3. 管理员在分支中手工修改相应的 `config/*.json`、Schema 和文档；配置变更时同步提升 `config/version.json`。
4. 运行 `npm run check`，提交 Pull Request，待 CI 通过后合并。

## 未知标签

未知或并列匹配的标签会作为自由话题保留在媒体记录中，不会自动创建待审核项，也不会自动加入标签词典。若要把自由话题升格为标准标签、并入既有别名或加入忽略词，应按上述 Git 维护流程处理。

## 当前待办

当前没有由本文件驱动的可执行待办。实际待审核状态以 D1 中的审核队列为准；历史词条决定可通过 Git 提交记录和变更日志追溯。

## 历史记录
