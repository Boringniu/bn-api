# 待定词条与操作说明

以后只编辑仓库根目录的
[review-decisions.json](../review-decisions.json)，不要直接删除或修改
演员、标签、忽略词配置。

格式固定为：

```json
[
  ["三上", "1"],
  ["无码中字", "1", "中文字幕"],
  ["日本电影", "2"]
]
```

- `["词", "1"]`：作为新 `#话题` 通过；能唯一匹配现有标准话题时自动作为同义词。
- `["词", "1", "标准话题"]`：明确把它作为现有标准 `#话题` 的同义词。
- `["词", "2"]`：否定并忽略。
- 系统自动判断它属于演员位 `#话题`、分类位 `#话题` 还是题材位 `#话题`，
  并放到索引对应位置。
- 每行之间必须有英文逗号，词、数字和同义词目标都要使用英文双引号。
- 没有决定时文件内容保持 `[]`。
- GitHub 提交后，Actions 自动校验、修改配置、提升版本、部署 Worker、
  重编目旧数据并刷新置顶索引。
- 成功后决定文件会自动恢复成 `[]`，不用手工删除已经处理的行。
- 你不需要区分“分类”和“标签”，它们在 Telegram 里都是 `#话题`，只是
  在置顶索引中的排列位置不同。
- 找不到待审核词、词义有歧义或格式错误时，自动化会停止，不会猜着修改。
